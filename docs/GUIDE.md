# دليل استخدام قوالب صفحات الهبوط

## إضافة القالب
1. من لوحة تحكم متجرك: **قنوات البيع ← صفحات الهبوط**.
2. اختر أحد القوالب (عطور أو عناية بالبشرة) ثم أنشئ الصفحة.
3. كل قسم في الصفحة مكوّن مستقل: اضغط أيقونة العين لإخفائه أو إظهاره، واسحبه لتغيير ترتيبه.

## الأقسام المتوفرة

| القسم | ماذا يعرض |
|---|---|
| المنتج الرئيسي | صور المنتج، التقييم، السعر والخصم، زر الشراء، شعارات الدفع، بطاقة الثقة، رأي عميل، أسئلة شائعة |
| خطوات التحوّل | من 2 إلى 4 خطوات بأيقونات توضّح رحلة العميل مع المنتج |
| المزايا | صفوف صورة ونص متبادلة، وصندوق "ماذا يوجد داخل العلبة"، وزر شراء |
| الفوائد | صفوف صورة ونص متبادلة لفوائد المنتج |
| آراء العملاء | تقييمات مكتوبة، وفيديوهات (يوتيوب، فيميو، تيك توك، أو ملف mp4)، وصور العملاء |
| مميزات المتجر | الشحن والدفع والدعم والاسترجاع |
| الدعوة الأخيرة | عنوان ختامي مع زر الشراء وصورة خلفية اختيارية |

## زر الشراء
- زر **المنتج الرئيسي** يشتري المنتج مباشرة، أو يضيفه للسلة، أو يفتح رابطاً تحدده.
- أزرار باقي الأقسام تنقل العميل إلى قسم المنتج الرئيسي أعلى الصفحة (أو تفتح رابطاً تحدده)، حتى يبقى للصفحة هدف شراء واحد.
- استخدم نفس لون الزر في كل الأقسام.

## اللغات
كل النصوص تُكتب بالعربية والإنجليزية من نفس الحقل (زر AR / EN)، وتتغير اتجاهات الأقسام تلقائياً حسب لغة المتجر.

## مقاسات الصور المقترحة
- صور المنتج: مربعة 1000×1000.
- صور المزايا والفوائد: 1200×900 (نسبة 4:3).
- صور العملاء: مربعة 600×600.
- غلاف الفيديو: طولي 720×1280.
- خلفية الدعوة الأخيرة: 1920×800.
