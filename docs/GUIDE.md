# دليل استخدام قوالب صفحات الهبوط

## إضافة القالب
1. من لوحة تحكم متجرك: **قنوات البيع ← صفحات الهبوط**.
2. اختر أحد القوالب (عطور، عناية بالبشرة، أو إلكترونيات) ثم أنشئ الصفحة.
3. كل قسم في الصفحة مكوّن مستقل: اضغط أيقونة العين لإخفائه أو إظهاره، واسحبه لتغيير ترتيبه.

## الأقسام المتوفرة

| القسم | ماذا يعرض |
|---|---|
| المنتج الرئيسي | شريط مزايا علوي، صور المنتج، التقييم، السعر والخصم، عروض الكمية، زر الشراء، شعارات الدفع، بطاقة الثقة، رأي عميل، تبويبات (الوصف، الاستخدام، الشحن)، وشريط "موصى به من" |
| خطوات التحوّل | من 2 إلى 4 خطوات بأيقونات توضّح رحلة العميل مع المنتج |
| المزايا | صفوف صورة ونص متبادلة، وصندوق "ماذا يوجد داخل العلبة"، وزر شراء |
| الفوائد | صفوف صورة ونص متبادلة لفوائد المنتج |
| آراء العملاء | تقييمات مكتوبة، وفيديوهات (يوتيوب، فيميو، تيك توك، أو ملف mp4)، وصور العملاء |
| مميزات المتجر | الشحن والدفع والدعم والاسترجاع |
| المقارنة | جدول يقارن منتجك بمنافسَين (متوفر / جزئياً / غير متوفر) مع صورة جانبية |
| الأسئلة الشائعة | عنوان ومقدمة بجانب قائمة أسئلة قابلة للفتح والإغلاق، وزر شراء اختياري |
| الدعوة الأخيرة | عنوان ختامي مع زر الشراء وصورة خلفية اختيارية |

## ربط المنتج الرئيسي بمنتج من متجرك
1. افتح قسم **المنتج الرئيسي** واختر منتجك من حقل **المنتج المرتبط بالصفحة**.
2. يظهر سعر المنتج الحقيقي وصوره وخياراته (المقاس، اللون…) تلقائياً، ويُعطَّل الزر إذا نفدت الكمية.
3. اترك الحقل فارغاً إذا أردت كتابة السعر والصور يدوياً (للعرض فقط أو مع رابط مخصص).

## العروض فوق زر الشراء
- **تلقائي** (الافتراضي): إذا كان تطبيق **عروض المنتجات والباقات** مثبّتاً تظهر عروضه للمنتج المرتبط، وإلا تظهر عروض الكمية التي كتبتها في القسم.
- **عروض الكمية**: بطاقات (قطعة / قطعتان / 3 قطع) تختار الكمية التي تُضاف للسلة. السعر المكتوب في البطاقة للعرض فقط، أما السعر النهائي فتحسبه السلة حسب عروض متجرك (مثل عروض سلة "اشترِ X واحصل على Y" أو خصم الكمية).
- **التطبيق فقط** أو **بدون عروض**.
- يمكن أيضاً إظهار زر **الطلب السريع** (إذا كان مفعّلاً في إعدادات متجرك) وعروض سلة الخاصة بالمنتج.

## زر الشراء
- زر **المنتج الرئيسي** يضيف المنتج للسلة ثم ينقل العميل لإتمام الطلب، أو يضيفه ويبقى في الصفحة، أو يفتح رابطاً تحدده.
- أزرار باقي الأقسام تنقل العميل إلى قسم المنتج الرئيسي أعلى الصفحة (أو تفتح رابطاً تحدده)، حتى يبقى للصفحة هدف شراء واحد.
- استخدم نفس لون الزر في كل الأقسام.

## اللغات
كل النصوص تُكتب بالعربية والإنجليزية من نفس الحقل (زر AR / EN)، وتتغير اتجاهات الأقسام تلقائياً حسب لغة المتجر.

## مقاسات الصور المقترحة
- صور المنتج: مربعة 1000×1000 (حتى 6 صور، أو تُستخدم صور المنتج المرتبط تلقائياً).
- صورة المقارنة: مربعة 1000×1000.
- صور المزايا والفوائد: 1200×900 (نسبة 4:3).
- صور العملاء: مربعة 600×600.
- غلاف الفيديو: طولي 720×1280.
- خلفية الدعوة الأخيرة: 1920×800.
